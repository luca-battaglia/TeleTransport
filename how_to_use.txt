TeleTransport – Come usarlo (Windows / PowerShell)

CONTENUTO CARTELLA
- treni.py        (Trenitalia / LeFrecce via Playwright + API BFF)
- voli.py         (Google Flights via SerpApi)
- travel_ranker.toml (config opzionale)
- requirements.txt
- treni.bat / voli.bat (launcher da riga di comando)

REQUISITI
- Python 3.11+ consigliato (OK anche 3.12/3.13/3.14)
- Connessione internet
- Per voli.py: chiave SerpApi (SERPAPI_KEY)

1) INSTALLAZIONE (una volta sola sul PC)
Apri PowerShell:

cd C:\TeleTransport
py -m venv .venv
.\.venv\Scripts\Activate.ps1

python -m pip install --upgrade pip
pip install -r requirements.txt

# Browser Playwright (per treni.py)
python -m playwright install chromium

NOTE:
- Su Windows serve tzdata per ZoneInfo (già in requirements.txt).
- treni.py prova prima Chrome di sistema; se manca usa Chromium Playwright.

2) CONFIG (opzionale)
File: travel_ranker.toml
Ordine precedenza: CLI > TOML > default

Ricerca automatica TOML (se non passi --config):
- ./travel_ranker.toml
- C:\Users\<utente>\.config\travel_ranker.toml
- oppure variabile ambiente:
  TRAVEL_RANKER_CONFIG=C:\TeleTransport\travel_ranker.toml

3) LANCIO “DA OVUNQUE” CON COMANDI (consigliato)
Hai messo C:\TeleTransport nel PATH e usi i .bat.

Assicurati di avere:
- C:\TeleTransport\voli.bat
- C:\TeleTransport\treni.bat

Contenuto consigliato .bat (usa sempre la venv, non serve attivarla):

voli.bat:
  @echo off
  set "DIR=%~dp0"
  "%DIR%.venv\Scripts\python.exe" "%DIR%voli.py" %*

treni.bat:
  @echo off
  set "DIR=%~dp0"
  "%DIR%.venv\Scripts\python.exe" "%DIR%treni.py" %*

Da qualunque cartella:
- voli ...
- treni ...

4) USO – VOLI (voli.py)
Serve SERPAPI_KEY:
- (persistente)  setx SERPAPI_KEY "LA_TUA_CHIAVE"
- (solo sessione) $env:SERPAPI_KEY="LA_TUA_CHIAVE"
Oppure: --api-key "LA_TUA_CHIAVE"

Preset route:
- zrh-bri, trn-bri, bri-zrh, bri-trn

Formati date/range accettati:
- 2026-02-11..2026-02-13
- 11-13/02
- 11/02 (anno inferito)

Esempi:
- Solo andata (preset):
  voli zrh-bri 11-13/02 --one-way

- A/R (preset):
  voli zrh-bri 11-13/02 24-25/02

- Custom IATA:
  voli --from ZRH --to BRI 11-13/02 --one-way

Opzioni utili:
- --limit N             (righe stampate)
- --min-price N         (scarta prezzi troppo bassi/anomali)
- --no-deep-search      (più veloce, meno completo)
- --no-show-hidden      (esclude hidden flights)
- --no-cache            (forza refresh SerpApi)

Output:
- SOLO tabella su stdout
- errori/progresso su stderr

5) USO – TRENI (treni.py)
Preset route:
- torino-zurigo
- alessandria-zurigo
- zurigo-torino
- zurigo-alessandria

Formati date/range:
- 2026-02-11..2026-02-13
- 11-13/02
- 11/02 (anno inferito)

Esempi:
- Singola tratta (preset):
  treni torino-zurigo 11-13/02

- Tratta custom:
  treni --from "Torino ( Tutte Le Stazioni )" --to "Zurigo HB" 11-13/02

- Andata + ritorno:
  treni torino-zurigo 11-13/02 --reverse
  (oppure 2 range: ANDATA RITORNO)
  treni torino-zurigo 11-13/02 24-25/02 --reverse

Opzioni utili:
- --min-price X
- --max-per-day N
- --limit N
- --verbose
- --sniff-out log.json   (debug chiamate)

Wizard:
- Se lanci senza argomenti e in terminale interattivo:
  treni
  (mostra menu e chiede tratta/range)

6) TROUBLESHOOTING RAPIDO
- “ZoneInfoNotFoundError Europe/Rome”:
  pip install tzdata

- treni.py non trova browser:
  python -m playwright install --force chromium

- “voli” / “treni” non trovati:
  verifica PATH contenga C:\TeleTransport
  e che esistano voli.bat / treni.bat in quella cartella.
  In PowerShell:
    Get-Command voli -All
    Get-Command treni -All
